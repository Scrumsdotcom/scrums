# /company/initiatives

Strategic changes — time-bounded, decomposable, measurable. Each initiative declares the goals it advances, the metrics it moves, and the tasks it decomposes into.

One file per initiative, named `INIT-<scope>-<n>.yaml`. Validate against [`/schemas/initiative.schema.json`](../../schemas/initiative.schema.json).

The worked example `INIT-FIN-0001-monthly-close-automation.yaml` lives here.
