# /company/domains

The three canonical domains.

| Domain | Owns |
|---|---|
| [`finance-ops`](./finance-ops) | finance, legal, people, suppliers, governance, operations, infra, reporting |
| [`product-operations`](./product-operations) | products, engineering, delivery, web, platform, architecture, QA, reliability, security, documentation |
| [`sales-marketing`](./sales-marketing) | marketing, sales, customer, partnerships, growth, brand, content, revenue operations |

Sub-domains may exist without a manifest as organizational placeholders. A folder with a manifest is a real module subject to modular monolith discipline.
