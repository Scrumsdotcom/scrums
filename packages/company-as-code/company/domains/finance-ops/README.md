# /company/domains/finance-ops

Finance & Ops domain. Sub-modules:

- [`finance`](./finance), P&L, cash, runway, billing reconciliation
- [`legal`](./legal), contracts, IP, entity structure
- [`people`](./people), workforce state, lifecycle events, comp
- [`suppliers`](./suppliers), third-party relationships, procurement
- [`operations`](./operations), internal ops, day-to-day coordination
- [`governance`](./governance), compliance, audit, controls
- [`infra`](./infra), internal infrastructure (corp IT, finance systems)
- [`reporting`](./reporting), board / investor reporting cadences

Sub-modules without manifests are organizational placeholders. The `finance` module is fully scaffolded as a worked example.
