# /company/domains/product-operations

Product & Operations domain. Sub-modules:

- [`web`](./web) — public web surfaces, marketing site
- [`products`](./products) — product lines and their internal teams
- [`platform`](./platform) — shared platform: identity, billing, deployment, observability
- [`delivery`](./delivery) — engineering delivery, release management
- [`architecture`](./architecture) — system architecture, ADR ownership
- [`security`](./security) — security posture, vulnerability response
- [`qa`](./qa) — quality engineering, test infrastructure
- [`reliability`](./reliability) — SRE, incident management, error budgets
- [`documentation`](./documentation) — engineering docs, public dev portal

Sub-modules without manifests are organizational placeholders. The `platform` module is fully scaffolded as a worked example.
