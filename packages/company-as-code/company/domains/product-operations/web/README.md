Organizational placeholder for the **web** sub-module. No manifest is declared yet, this folder claims structure, not runtime authority.

To activate this module:

1. Author `manifest.yaml` declaring `owns`, `consumes`, `exposes`, and at least one accountable contact.
2. Add the manifest path to validation by running `cd cli && npm run validate`.
3. Add any agents, workflows, or playbooks the module owns.

See [`/templates/module-manifest.yaml`](../../../../templates/module-manifest.yaml) for a starting point.
