# /templates

Framework-level authoring templates. Annotated starting points for every canonical primitive. Copy a template, fill in the placeholders, validate.

| Template | For |
|---|---|
| [`module-manifest.yaml`](./module-manifest.yaml) | New module |
| [`agent.yaml`](./agent.yaml) | New autonomous unit |
| [`workflow.yaml`](./workflow.yaml) | New orchestration |
| [`task.yaml`](./task.yaml) | New canonical task |
| [`initiative.yaml`](./initiative.yaml) | New strategic initiative |
| [`goal.yaml`](./goal.yaml) | New KPI / OKR / SLA |
| [`metric.yaml`](./metric.yaml) | New metric definition |
| [`playbook.md`](./playbook.md) | New runbook / SOP |
| [`plan.md`](./plan.md) | New plan (park-friendly) |
| [`adr.md`](./adr.md) | New Architecture Decision Record |
| [`skill.yaml`](./skill.yaml) | New Tier-3 skill (cross-runtime, generates Claude SKILL.md + AGENTS.md + Gemini Gem) |

Company-level template variants live at [`/company/templates`](../company/templates).
