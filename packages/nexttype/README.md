# NextType tooling

This folder holds the tooling for [NextType](https://github.com/Scrumsdotcom/nexttype), the experimental execution language for agents.

| Repository | What it holds |
|---|---|
| [`Scrumsdotcom/nexttype`](https://github.com/Scrumsdotcom/nexttype) | The language: its specification, reference, examples and research. |
| `Scrumsdotcom/scrums` (this folder) | The tooling around the language: CLI wrappers, editor support and build scripts. |

New tooling goes in this folder, not in the language repository.

## Status

NextType is a design preview. There is no compiler yet.
This folder holds no tools yet.

The `nt` preview CLI is published on npm as [`@scrums/nexttype`](https://www.npmjs.com/package/@scrums/nexttype):

```bash
npx @scrums/nexttype help
```
