## Overview

When you connect Jira to your organization on [Scrums.com](https://www.scrums.com), we automatically combine your Jira and Git data to provide insight into your planning and delivery process. We collect only the metadata required to provide value- never your issue content or attachments. Sensitive data, such as project keys and issue summaries, are always encrypted.

## Why Integrate Jira with [Scrums.com](https://www.scrums.com)?

- **Automated Analytics:** Gain insights into your team's planning, delivery, and Sprint metrics.
- **No Code Changes Needed:** Integration is secure and token-based, requiring no changes to your Jira projects.
- **Real-Time & Historical Data:** See results in minutes, with both real-time and historical analysis.

## Permissions

We request only the necessary permissions to analyze Jira metadata. Below is a description of the scopes requested when connecting to Jira:

- **Projects:** Read access to project metadata, boards, and sprints.
- **Issues:** Read access to issue metadata, statuses, and transitions.
- **Users:** Read access to user profiles and assignments.

We require read access to metadata for issues, boards, and sprints. Jira’s API requires broad read permissions to access these endpoints. **We never read, transmit, or store issue descriptions or attachments.**

 

## Step-by-Step Integration Instructions

 

### 1. Log in to [Scrums.com](https://www.scrums.com)

- Go to [Scrums.com](https://www.scrums.com) and sign in to your account.

### 2. Navigate to Integrations

- In your dashboard, click on your profile or account menu.
- Select **Integrations** from the dropdown or sidebar.

### 3. Add a New Jira Integration

- Click **Add Integration** and select **Jira** from the list of available integrations.
- Choose the project you want to link to Jira.

### 4. Authorize [Scrums.com](https://www.scrums.com) to Access Jira

- Enter your Jira base URL, API token, and associated user email.
- Generate a [Jira API token](https://id.atlassian.com/manage-profile/security/api-tokens) if you don’t have one.
- Click the green checkbox to save.
- Click **Verify** to confirm endpoints are correct.

### 5. Add Jira Projects

- Click **Add** to add a project.
- Select the Jira instance and add the **Jira key** for the project.
- Click **Verify** to check the project code.

### 6. Data Sync & Dashboard

- [Scrums.com](https://www.scrums.com) will begin syncing your Jira data. Initial results appear within minutes, and the platform will continue to backfill historical data.
- Explore your analytics dashboards for real-time insights.

 

## Best Practices

- **Use a Long-Term Admin Account:** Set up integrations using an account that will remain active to avoid disruptions.
- **Token Security:** Store your Jira API token securely. Do not share it publicly.
- **Project Selection:** Only connect projects relevant to your analytics needs.

## Troubleshooting & Support

- **Authorization Issues:** Ensure your Jira account has the required permissions and correct API token.
- **Data Not Syncing:** Double-check your token permissions and project keys. Our integration page will alert you if a token has expired or a project key is invalid.
- **Need Help?** Contact support through your [Scrums.com](https://www.scrums.com) dashboard.
