## Overview

The Cursor integration connects your AI coding metrics with Scrums.com, enabling analytics and delivery insights. Compare teams using different AI tools to determine where you're getting the best ROI. We collect only the metadata required to provide value — never your code or sensitive content. Sensitive data, such as user IDs and project names, are always encrypted.

## Why integrate Cursor?

- **Automated analytics** — Gain insights into your team's AI coding activity, productivity, and usage patterns.
- **No code changes needed** — Integration is secure and key-based, requiring no changes to your codebase.
- **Real-time & historical data** — See results in minutes, with both real-time and historical analysis.
- **Cross-tool comparison** — Benchmark Cursor against other AI coding tools to measure ROI across your teams.

## Permissions

| Scope | Purpose |
| --- | --- |
| Admin API Key | Read access to team member information and daily usage data |

We never read, transmit, or store your source code.

## Requirements

- Admin access to your Cursor team account
- Scrums.com workspace Admin access

## Setup

<Steps>
  <Step title="Generate a Cursor Admin API Key">
    In Cursor, go to **Account Settings** and generate an **Admin API key** with access to your team's data. For detailed instructions, see [Cursor's API documentation](https://docs.cursor.com/).
  </Step>
  <Step title="Log in to Scrums.com">
    Go to [Scrums.com](https://scrums.com/) and sign in to your account.
  </Step>
  <Step title="Navigate to Integrations">
    In your dashboard, click on your profile or account menu and select **Integrations** from the dropdown or sidebar.
  </Step>
  <Step title="Add Cursor">
    Click **Add Integration** and select **Cursor** from the list. Choose the project you want to link. Paste your Cursor Admin API key into the integration form and click the green checkbox to save.
  </Step>
  <Step title="Verify the connection">
    Click **Verify** to confirm the connection is working correctly.
  </Step>
  <Step title="Data sync">
    Scrums.com will begin syncing your Cursor data. Initial results appear within minutes, and the platform will continue to backfill historical data. Explore your analytics dashboards for real-time insights.
  </Step>
</Steps>

## Best practices

- **Use a long-term admin account** — Set up the integration with an account that will remain active to avoid disruptions.
- **API key security** — Store your Cursor Admin API key securely. Do not share it publicly.
- **Key permissions** — Ensure your API key has the correct permissions for the most detailed insights.

## What this unlocks

Connecting Cursor to Scrums.com gives your team:

- Transparency and accountability across teams
- Data-driven retrospectives and planning sessions
- Real-time AI coding metrics to identify bottlenecks

## Troubleshooting

| Issue | Resolution |
| --- | --- |
| Authorization error | Ensure your Cursor account has the required permissions and a valid Admin API key |
| Data not syncing | Double-check your API key and analytics settings — the integration page will alert you if a key has expired or is invalid |
| Need help? | Contact support through your [Scrums.com](https://scrums.com/) dashboard |
