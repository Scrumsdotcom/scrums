## A foundation from the 1970s

Per Martin-Löf developed intuitionistic type theory during the 1970s. Dependent types let a type refer to a value. This gives specifications a place in the language itself.

- [Martin-Löf: An Intuitionistic Theory of Types](https://github.com/michaelt/martin-lof/blob/master/pdfs/An-Intuitionistic-Theory-of-Types-1972.pdf): Archived early primary paper.

## Working systems to learn from

- [Lean 4 — elaboration and checking](https://lean-lang.org/doc/reference/latest/Elaboration-and-Compilation/): Separate proof discovery from checking a supplied proof.
- [Idris 2 — quantitative type theory](https://arxiv.org/abs/2104.00480): Dependent execution, erasure, and resource use.
- [F* — proofs and effects](https://fstar-lang.org/): Proof-oriented programming with effectful computations.
- [Unison — code identity](https://www.unison-lang.org/docs/the-big-idea/): Definitions identified by content rather than their names.
- [Ur/Web — one source across tiers](https://adam.chlipala.net/papers/UrWebPOPL15/UrWebPOPL15.pdf): A typed programming model spanning web application layers.
- [Dependent Types for JavaScript](https://arxiv.org/abs/1112.4106): Earlier work connecting dependent reasoning and JavaScript.
