## What NextType is

NextType is an experimental execution language for agents.
It has three core ideas:

- **TypeScript lineage.** People review a readable, TypeScript-style view of each contract. Agents write a compact form of the same contract. See [One contract, two views](/nexttype/language/two-views).
- **Dependent types are the spec.** A type can refer to a value. So a type can state "the total equals the sum of the lines". The compiler checks that the code satisfies it. See [Contracts](/nexttype/language/contracts).
- **Tokens per accepted change.** The main metric is the total model tokens across all attempts, divided by the changes that pass acceptance. Failed attempts count. See [Benchmark design](/nexttype/benchmarks).

Programs are typed compiler graphs.
Agents send compact patches and receive explicit obligations.
People approve intent and assumptions.
An independent checker checks each implementation against the fixed contract.

## Safety warning

NextType is experimental.
Expect breaking changes, rough edges, and security issues.
Run it in isolated workspaces, not against production systems or sensitive data.
