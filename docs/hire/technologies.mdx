## Describe the work, not only the keyword

Technology names are useful filters, but they do not define a role by themselves. Include the runtime, framework, architecture, operational context, and expected responsibility.

For example, a request for Python should also identify whether the work involves APIs, data pipelines, machine learning, automation, or platform tooling.

## Build a technology profile

Separate:

- Required production experience
- Preferred adjacent technologies
- Architecture and scale requirements
- Cloud, data, security, or compliance context
- Testing and operational responsibilities
- Evidence you want to review

The live [Hire directory](https://www.scrums.com/hire) contains the current technology taxonomy and availability. Each technology has its own www page at `https://www.scrums.com/hire/{technology}-developers`, for example [React developers](https://www.scrums.com/hire/react-developers); those pages are the register and are not duplicated in the docs. Catalog infrastructure is documented separately under [AI Infrastructure](/catalog/infrastructure).
