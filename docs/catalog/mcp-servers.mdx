## Catalog MCP servers

An MCP server exposes tools or context to compatible AI clients. A catalog record describes the server, provider, supported tools, connection requirements, and deployment options.

Before connecting a server:

- Inspect the tools it exposes.
- Identify read, write, and destructive actions.
- Grant the smallest credential scope that works.
- Confirm data handling and network requirements.
- Require approval for sensitive operations.
- Test failure handling and audit records.

An MCP server supplies tools. The [MCP Gateway](/platform/mcp-gateway) governs who can discover and call them.
