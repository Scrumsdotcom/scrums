## Catalog agents

An AI agent is a deployable software worker designed to perform a defined task. Catalog records describe an agent's purpose, provider, requirements, and commercial terms.

Before you deploy an agent:

1. Define the task and acceptance criteria.
2. Review required context and tool access.
3. Set approval boundaries for sensitive actions.
4. Confirm where data and code are processed.
5. Select an evaluation and monitoring approach.
6. Assign the deployment to a workspace.

The [AI Agent Harness](/platform/agent-harness) supplies shared operational controls. The [MCP Gateway](/platform/mcp-gateway) governs tool access when an agent uses MCP.
