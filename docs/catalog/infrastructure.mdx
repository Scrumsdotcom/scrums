## Infrastructure catalog

AI infrastructure includes the managed services that applications, agents, and delivery workflows run on.

Common categories include:

- Compute and model runtime
- Containers and orchestration
- Storage, databases, caches, and queues
- Networking and content delivery
- Observability and incident tooling
- Data pipelines and analytics
- Security and deployment services

## Evaluate a record

Confirm the provider, region, service limits, availability commitment, security controls, metering unit, and operational ownership before deployment.

Infrastructure availability is distinct from engineering skill coverage. See [Hire technologies](/hire/technologies) when you need engineers experienced with a technology.
