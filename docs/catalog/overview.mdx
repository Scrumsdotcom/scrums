## What the catalog contains

The [Scrums.com AI Catalog](https://www.scrums.com/catalog) contains deployable records used by engineering organizations.

| Class | What it contains |
|---|---|
| [AI agents](/catalog/agents) | Software workers designed for defined tasks |
| [AI models](/catalog/models) | Foundation, reasoning, embedding, multimodal, and specialist models |
| [MCP servers](/catalog/mcp-servers) | Tool and context connections that use Model Context Protocol |
| [Agent skills](/catalog/skills) | Reusable instructions and workflows |
| [AI APIs](/catalog/apis) | External programmable services used by AI systems |
| [AI infrastructure](/catalog/infrastructure) | Compute, runtime, data, observability, and deployment primitives |

AI Development scopes and Hire engineers are separate surfaces. They run on the same platform, but they are not AI Catalog classes.

## Before you deploy

For each record, review:

- The provider and deployment region
- Inputs, outputs, and supported use cases
- Data handling and retention
- Required credentials and integrations
- Pricing and metering units
- Approval, audit, and support requirements

Availability and catalog inventory can change. Use the live catalog record as the source for current commercial and availability details.
