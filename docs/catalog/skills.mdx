## What a skill is

An agent skill packages instructions, conventions, and a repeatable workflow for a defined task. A skill can improve consistency without granting access by itself.

Review these details before use:

- Intended task and required inputs
- Supported agents or clients
- Version and change history
- Required tools and permissions
- Expected outputs and limitations
- Evaluation cases and acceptance criteria

Treat skill content as code. Review changes, pin versions where supported, and retest the workflow when its instructions or dependencies change.
