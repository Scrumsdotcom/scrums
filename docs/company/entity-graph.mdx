## Overview

Scrums.com publishes two machine-readable files about the company. Search engines, AI assistants and integrations can use them to identify Scrums.com and its relationships.

- [Organization entity (entity.json)](https://www.scrums.com/entity.json)
- [Relationship graph (graph.json)](https://www.scrums.com/graph.json)

`entity.json` is a Schema.org `Organization` record. It contains the company identity, offers, locations, contact points, public profiles and the product taxonomy.

`graph.json` contains relationships about the company: leadership, founders, key events, semantic triples and certifications.

## Identifiers and URLs

- The organization identifier is `https://www.scrums.com/#organization`.
- Public website URLs use `https://www.scrums.com`.
- AI Catalog classes and records use `/catalog`.
- Delivery scopes use `/ai-development/scopes`.
- Engineer profiles use `/hire/engineers`.
- Product and API documentation uses `/docs`.
