## Overview

The Scrums.com entity graph provides machine-readable organization data and relationships for search, retrieval, and integration use cases.

<Warning>
The structured exports are still being verified. Fields containing `VERIFY` are placeholders and must not be treated as confirmed facts.
</Warning>

## Exports

- [Organization entity JSON](/company/entity.json)
- [Relationship graph JSON](/company/graph.json)

`entity.json` contains the primary organization record and canonical product taxonomy. `graph.json` contains relationships, semantic triples, provenance, and verification status.

## Canonical URL rules

- Use `https://www.scrums.com` for public website URLs.
- Use `/catalog` for AI Catalog classes and records.
- Use `/ai-development/scopes` for delivery scopes.
- Use `/hire/engineers` for engineer profiles.
- Use `/docs` for product and API documentation.

Only values marked as verified in the exports should be reused as factual claims.
