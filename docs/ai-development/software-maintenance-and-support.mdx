Software maintenance runs as a managed scope on a Delivery Plan: 24/7 monitoring, bug fixes and incident response under SLA, security patches, performance work and mobile app upkeep. Scrums.com owns uptime and response times, and every incident, fix and release is visible in one dashboard.

Managed delivery arrives as a scope on a [Delivery Plan](/ai-development), not as a separate engagement model. Response and patch targets for critical production issues, high-priority bugs, vulnerabilities and mobile crashes are stated on the www page and confirmed when the scope is agreed. The scope includes platform access, AI Agent Gateway monitoring, a dedicated account manager, and weekly, monthly and quarterly reporting. Maintenance work runs in the same backlog as new features. For response SLAs across several systems, use the [Factory tier](/ai-development#plan-tiers). The current price is on the [AI Development page](https://www.scrums.com/ai-development#pricing) and on each service page.
