Software maintenance runs on a retainer on the Scrums.com platform: 24/7 monitoring, bug fixes and incident response under SLA, security patches, performance work and mobile app upkeep. Scrums.com owns uptime and response times, and every incident, fix and release is visible in one dashboard.

The retainer is a [managed delivery](/ai-development/managed-delivery) service line rather than a bounded scope. Response and patch targets for critical production issues, high-priority bugs, vulnerabilities and mobile crashes are stated on the www page and confirmed in the service-line agreement. The retainer includes platform access, AI Agent Gateway monitoring, a dedicated account manager, and weekly, monthly and quarterly reporting. Maintenance work can also run on a [Delivery Plan](/ai-development/delivery-plans), in the same backlog as new features. For response SLAs across several systems, use [Enterprise delivery](/ai-development/enterprise-delivery). Current prices are on the [pricing page](https://www.scrums.com/pricing).
