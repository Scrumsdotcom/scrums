Custom AI agents are built, integrated and run as scoped workstreams on the Scrums.com platform: support, document, research and voice agents for the business, and QA, review and release agents inside your SDLC. Every agent is governed through the [AI Agent Gateway](/platform/ai-gateway) and runs inside the [AI agent harness](/platform/agent-harness).

Delivery follows four stages. Discovery and architecture maps the workflows, toolchain and automation candidates and defines the governance framework and success metrics. Agent setup provisions the platform and gateway environment, integrates your tools, deploys pilot agents and configures access control. Rollout starts with low-risk automation such as testing and code analysis, then moves to deployment orchestration and incident response as value is demonstrated. Scale and optimise measures ROI and improves agent accuracy through feedback loops. This service runs on a [Delivery Plan](/ai-development/delivery-plans). One plan gives you one active workstream: a managed team, one delivery owner and one prioritised backlog that also holds your other development work. You queue requests or [scopes](/ai-development/scopes), and the team delivers them one at a time, in your order. First code reaches production within 48 hours of access. The first agreed deliverable ships within 14 days, or the first month is free. For parallel workstreams, use [Enterprise delivery](/ai-development/enterprise-delivery). Current prices are on the [pricing page](https://www.scrums.com/pricing).
