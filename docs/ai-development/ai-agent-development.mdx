Custom AI agents are built, integrated and run as scoped workstreams on the Scrums.com platform: support, document, research and voice agents for the business, and QA, review and release agents inside your SDLC. Every agent is governed through the [AI Agent Gateway](/platform/ai-gateway) and runs inside the [AI agent harness](/platform/agent-harness).

Delivery follows four stages. Discovery and architecture maps the workflows, toolchain and automation candidates and defines the governance framework and success metrics. Agent setup provisions the platform and gateway environment, integrates your tools, deploys pilot agents and configures access control. Rollout starts with low-risk automation such as testing and code analysis, then moves to deployment orchestration and incident response as value is demonstrated. Scale and optimise measures ROI and improves agent accuracy through feedback loops. Scrums.com provisions this service as scoped workstreams on the platform. You pick the scopes, Scrums.com owns the outcome milestone by milestone, and every sprint is visible in one dashboard. Each workstream runs on a delivery plan; current plans and prices live on the [pricing page](https://www.scrums.com/pricing). To start, select a scope on the www page or in [Scopes](/ai-development/scopes), complete checkout, and assign the resulting deployment to a workspace. Use [Choose a delivery model](/ai-development/choose-delivery-model) if you are not sure this is the right shape.
