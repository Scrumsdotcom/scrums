## Overview

Scrums.com's model is human-led, AI-augmented. Every engagement is delivered by skilled engineers who use AI tools to work faster, make better decisions, and maintain higher quality — not to replace judgment or creativity.

## Principles of the Model

**Engineers own outcomes.**
AI Agents assist but do not make delivery decisions. Engineers review all AI-generated output — code suggestions, test results, documentation — before it is accepted.

**AI handles repetition.**
Tasks like regression test execution, documentation generation, and status reporting are handled by AI, freeing engineers to focus on complex, creative, and high-value work.

**Governance is always on.**
All AI activity within SEOP is logged, attributable, and auditable. Nothing happens outside the governance boundary.

**Improvement is continuous.**
AI performance improves over time as it learns from each engagement — better test coverage, more accurate risk signals, more relevant code suggestions.
