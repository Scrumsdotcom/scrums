### Overview

Platform administration covers user management, workspace configuration, billing, integrations, and security settings. Administrative capabilities scale with your subscription tier.

### Admin features by tier

| Feature | Access | Business | Enterprise |
| :--- | :--- | :--- | :--- |
| User invitations | ✓ | ✓ | ✓ |
| Role-based access control | Standard | Full RBAC | Advanced |
| SSO / SAML and SCIM | — | — | ✓ |
| Customer audit logs | — | — | ✓ |
| API access | — | ✓ | ✓ |
| Enablement | Self-serve | Enablement Partner | Enablement Team |
| Billing management | Self-serve | Invoiced | Dedicated support |

See [pricing](https://www.scrums.com/pricing) for current limits and commercial terms.
